Skip-gram and Transformer embeddings

A short note connecting the two guides: How train_skip_gram works and How one attention head works.

The analogy

A Transformer does not use skip-gram embeddings. It starts its own embedding table from random numbers and trains it along with the rest of the model. But skip-gram's embedding table and a Transformer's embedding table are the same mechanism: a learned table with one vector per token, picked out by a one-hot input, and trained by nudging weights to reduce a loss. Only the training signal is different.

The clarification: which part is analogous

The analogy covers the ends of a Transformer, not the whole thing. The full skip-gram network is like a Transformer with its middle removed:

In one sentence: skip-gram is a good model of a Transformer's first step (the input embedding table) and its last step (scoring with an output table). It has nothing that corresponds to the attention layers in between.

Why the middle matters

  • Static vs. contextual. Skip-gram gives "bank" one vector, whether it means a river bank or a money bank. A Transformer starts from one vector too, but every attention layer mixes in information from the surrounding tokens. By the time the vector reaches the output table, it describes "bank" in this sentence.
  • One token vs. the whole sentence. Skip-gram's score depends on one input token. A Transformer's prediction depends on every token so far, because attention lets each token gather information from the others.
  • The output table. Skip-gram's context_vector table and a Transformer's output table do the same job: one vector per token, dotted with the current vector to give a score. GPT-2 goes further and reuses its input embedding table as its output table.

For the full mechanics: the embedding table and its training are in the skip-gram guide. The middle, built neuron by neuron, is in the attention guide, and its section 2, Where x comes from, shows the Transformer's embedding table as neurons and synapses.
